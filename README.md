## Selected projects

### 📐 [VaREngine](https://github.com/keekee3091/VaREngine)
C++17 risk engine: Monte-Carlo simulation, Black-Scholes pricing and several VaR methodologies, with benchmarking integrated into CI/CD.

### 🤖 [mm_sim](https://github.com/keekee3091/market_maker_bot)
C++17 market-making simulator: order book, Avellaneda-Stoikov style quoting, Monte-Carlo simulated prices, inventory management. I'm documenting the build publicly on LinkedIn.

### 🛡️ [MLScoringKYC](https://github.com/keekee3091/MLScoringKYC)
KYC/AML scoring pipeline: LightGBM, PU-learning for unlabelled data, SHAP explainability, served through FastAPI with Redis caching.

### 🌌 [N-Body Simulator](https://github.com/keekee3091/nbody)
Physics simulation in C++ using CUDA and OpenMP for compute, SFML for real-time rendering.

### 📡 [NetPulse](https://github.com/keekee3091/NetPulse)
Network monitoring tool in C++.

### 📈 Prediction-market trading bot
Python bot on Polymarket (CLOB API) with a backtest framework and Kelly sizing module. A useful lesson in how stop-loss exits and a decent win rate can still produce a negative Sharpe, and the reason I'm moving towards market-making research.
